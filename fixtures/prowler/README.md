# Prowler findings fixtures

`nour-clinic-week1.ocsf.json` and `nour-clinic-week6.ocsf.json` are **synthetic**: no AWS
account was scanned. They are generated by `backend/app/demo_aws.py` for a fictional clinic
account (`111122223333`, the AWS documentation example id) and written by
`scripts/regen_fixtures.py`.

They follow the exact shape Prowler 5.50.0 writes for `-M json-ocsf`
(`prowler/lib/outputs/ocsf/ocsf.py`), use real check IDs, titles and severities from
`compliance/prowler/prowler-5.50.0-aws-checks.json`, and every item was validated against
`py_ocsf_models.events.findings.detection_finding.DetectionFinding`, the model Prowler itself uses.

Week 6 contains the demo regression: the `nour-patient-scans` bucket lost its public access
block, became public, and had access logging switched off.
